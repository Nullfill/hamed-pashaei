# 🚀 راهنمای راه‌اندازی گیت‌وی هاست ایران (PHP API Gateway)

این اسکریپت سبک پی‌اچ‌پی روی **هاست اشتراکی دایرکت‌ادمین ایران** شما قرار می‌گیرد و مشکل تغییر کاتالوگ فیلیمو و گپ‌فیلم با فیلترشکن را به صورت ۱۰۰٪ حل می‌کند.

---

## 🎯 چرا این روش بهترین راهکار است؟

1. **تشخیص آی‌پی در لایه سوکت (Socket Remote IP):**
   فیلیمو و گپ‌فیلم موقعیت کاربر را بر اساس IP واقعی اتصال TCP تشخیص می‌دهند و هدرهایی مثل `X-Forwarded-For` را عمداً نادیده می‌گیرند.
2. **هاست ایران = آی‌پی داخلی معتبر:**
   وقتی درخواست از هاست ایران شما ارسال می‌شود، فیلیمو و گپ‌فیلم آی‌پی دیتاسنتر ایرانی (آسیاتک، شاتل و...) را می‌بینند؛ در نتیجه متغیر `abroad: false` شده و **کاتالوگ کامل و بدون سانسور ایران** را تحویل می‌دهند.
3. **مصرف نزدیک به صفر ترافیک هاست:**
   این اسکریپت فقط پاسخ‌های متنی JSON (چند کیلوبایت) را رد می‌کند. **فایل‌های سنگین ویدیویی (MP4 و HLS .ts) اصلاً از هاست شما رد نمی‌شوند** و مستقیماً روی گوشی کاربر استریم می‌شوند. بنابراین حتی ارزان‌ترین هاست اشتراکی سال‌ها بدون افت سرعت پاسخگو خواهد بود.

---

## 🛠️ مراحل نصب در دایرکت‌ادمین (DirectAdmin)

1. وارد کنترل‌پنل **DirectAdmin** هاست ایران خود شوید.
2. به بخش **File Manager** بروید و وارد پوشه `public_html` شوید.
3. یک پوشه به نام `filimchi` بسازید (یا فایل را مستقیماً در روت قرار دهید).
4. فایل `api-gateway.php` را در آنجا آپلود کنید (یا یک فایل `index.php` بسازید و کدهای آن را درونش Paste کنید).
5. در صورت تمایل، مقدار ثابت `GATEWAY_SECRET` را در خط ۲۹ فایل به یک رمز اختصاصی تغییر دهید (مثلاً: `my-filimchi-secret-999`).

---

## 🧪 نحوه تست سلامت گیت‌وی

در مرورگر خود آدرس زیر را باز کنید:
```text
https://your-iran-host.com/filimchi/api-gateway.php?secret=filimchi-secret-2026&url=https://www.filimo.com/api/fa/v1/movie/movie/list/tagid/1
```
اگر خروجی JSON صفحه اصلی فیلیمو را بدون خطا مشاهده کردید، گیت‌وی شما آماده استفاده است!

---

## 📱 نحوه استفاده در اپلیکیشن موبایل یا وب

کافیست در اپلیکیشن کلاینت، آدرس‌های API را به فرمت زیر فراخوانی کنید:
```dart
final gatewayUrl = "https://your-iran-host.com/filimchi/api-gateway.php";
final targetApi = "https://www.filimo.com/api/fa/v1/movie/movie/list/tagid/1";

final response = await dio.get(
  gatewayUrl,
  queryParameters: {
    'url': targetApi,
  },
  options: Options(
    headers: {
      'X-Proxy-Secret': 'filimchi-secret-2026',
      'useragent': '{"os":"react","pf":"site"}',
      'jsonType': 'simple',
    },
  ),
);
```
